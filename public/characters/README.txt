キャラクターアバター画像の配置場所

以下の3ファイルをこのフォルダに置いてください(ファイル名は固定):

- avatar-home.png  … 未出勤(自宅リビング背景)
- avatar-work.png  … 出勤中(携帯ショップ店内背景)
- avatar-night.png … 退勤済み(夜の街並み背景)

マスター画像(4枚目)は現在どの画面でも直接表示していません。将来「仲間のタウン」
機能などで使う可能性があるため、参考として avatar-master.png という名前で
一緒に置いておいても構いません(未使用でもエラーにはなりません)。

配置後は特にコードの変更は不要です。src/app/clock/character-avatar.tsx が
上記のファイル名を直接参照しています。
